# facematch

Player controller page for a lab workshop memory-match game. The host (TV) screen runs locally; this page only has a name field and a 4x4 card pad. No photos are stored here.

# chartgod

Phone controller page for the "차트의 신" stock-chart workshop game. The host (TV) screen runs locally and holds the price data and answers; this page only receives what the room is allowed to see.
